XState is a JavaScript and TypeScript library for modeling and running application logic. It uses state machines and actors to describe how a system responds to events over time.

A **state machine** defines the states a system can be in and the transitions between them. For example, a media player can be stopped, playing, or paused. An event such as `play` can transition the player from stopped to playing. The machine can also hold data and run effects, such as starting a request.

An **actor** runs logic and communicates through events. You can create an actor from a state machine, send events to it, and read its current snapshot. Actors can also run other kinds of logic, including asynchronous tasks, and communicate with other actors.

XState works with JavaScript and TypeScript on the frontend and backend. It also provides integrations for frameworks including React, Vue, Svelte, and Solid.
