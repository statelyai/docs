You can embed your machines anywhere that supports [`<iframe>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/iframe). Embed mode is a focused non-editable view of your machine in Stately Studio’s editor, which can be zoomed and panned.

We love to use embedded machines in our docs! Below is an example of an embedded machine:

<EmbedMachine
  name="Embed feature machine"
  embedURL="https://editor.stately.ai/viz?machineId=e94d5674-7ab7-4a4e-b7a8-781609bfe523"
/>

To embed a live machine, keep its project **public**. In the machine's Share
dialog, select **Publish embed**, then copy the URL. A live public embed uses
the machine's existing ID; a pinned snapshot uses an opaque publication ID.
Readers do not need to sign in, and the embed
works on any site by default.

Free accounts can publish three public machines across projects. Pro accounts
can publish more machines, including pinned snapshots of private
or unlisted machines. A private source stays private, but anyone with its
published snapshot URL can view that snapshot. Free embeds display Stately
attribution. There is no per-view limit.

Read [how to change a project’s visibility settings](/docs/projects/#change-a-projects-visibility).

<Callout>

You can also [get your machine as an image](image) for platforms where `<iframe>` is not supported.

</Callout>

## Copy the embed URL

1. Open the machine in Stately Viz and select **Share**.
2. Select **Publish embed**. Publishing requires an account with edit access to the project.
3. Optionally choose theme, start mode, controls, and a responsive size under **Appearance**.
4. Select **Copy embed URL** or **Copy iframe**. [Find example code below](#example-iframe-code).

Use **Unpublish** to stop serving the embed and free a publication slot.

To limit where an embed appears, open **Restrict allowed domains (optional)**.
Changing restrictions later keeps existing embed URLs.

## Example `<iframe>` code

The following HTML embeds the same machine at the top of this page in dark mode:

```html
<iframe
  loading="lazy"
  src="https://editor.stately.ai/viz?machineId=e94d5674-7ab7-4a4e-b7a8-781609bfe523&theme=dark"
  style="display: block; width: 100%; aspect-ratio: 6 / 4;"
>
  <a
    href="https://editor.stately.ai/viz?machineId=e94d5674-7ab7-4a4e-b7a8-781609bfe523"
  >
    View the <em>Embed feature machine</em> in Stately Viz </a
  >.
</iframe>
```

<Callout>

The machine owner can unpublish the embed at any time. Private-source snapshots use a separate publication ID.

If you want us to prioritize improving embed mode, please [upvote it on our feedback page](https://github.com/statelyai/feedback/issues/94).

</Callout>

## URL parameters, including color mode

The embed URL has some of the same parameters as the [machine URL](url).

- **machineId**: an explicitly published live public machine.
- **publicationId**: the opaque ID for a pinned snapshot.
- **mode**: the current machine mode. For example, `mode=Design` or `mode=Simulate`
- **theme**: the color mode for the embedded machine. For example, `theme=light` or `theme=dark`. Legacy `colorMode` also works.

Add `&theme=light` or `&theme=dark` to force the color mode.
